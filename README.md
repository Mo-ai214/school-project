# مشروع المدرسة — نظام إدارة مدرسة متكامل

تطبيق ويب عربي (RTL) يجمع **موقعاً تعريفياً للمدرسة** و**لوحة إدارة كاملة**، مبني بـ React + TypeScript + Tailwind CSS.

## المزايا

### الموقع العام
- **الرئيسية**: تعريف بالمدرسة، إحصائيات، مزايا، آخر الأخبار.
- **عن المدرسة**: الرؤية والرسالة والقيم، المرافق، كلمة المدير.
- **الأخبار**: تصفية حسب التصنيف وصفحة لكل خبر.
- **استعلام النتائج**: يدخل ولي الأمر الرقم المدرسي فتظهر علامات الطالب ونسبة حضوره.
- **تواصل معنا**: نموذج تصل رسائله إلى لوحة الإدارة.

### لوحة الإدارة (`/admin`)
| القسم | الوظيفة |
|---|---|
| لوحة التحكم | إحصائيات ورسوم بيانية للحضور وتوزيع الطلاب |
| الطلاب | إضافة/تعديل/حذف، بحث وتصفية، ملف الطالب وشهادة قابلة للطباعة |
| المعلمون | إدارة المعلمين والمواد التي يدرّسونها |
| الصفوف | السعة، رائد الصف، الغرفة |
| المواد | الحصص الأسبوعية لكل مادة |
| الجدول الدراسي | عرض حسب الصف أو المعلم، تعديل الحصص مع كشف التعارض |
| الحضور والغياب | تسجيل يومي سريع لكل صف |
| العلامات | رصد (أعمال 20 + نصفي 30 + نهائي 50) لكل فصل |
| التقارير | معدلات المواد والصفوف، نسب النجاح، لوحة الشرف |
| الأخبار والرسائل | نشر أخبار الموقع واستقبال رسائل الزوار |
| الإعدادات | بيانات المدرسة، حساب المدير، نسخ احتياطي/استيراد |

**بيانات الدخول الافتراضية:** `admin` / `admin123` (يمكن تغييرها من الإعدادات).

## التشغيل

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # نسخة الإنتاج في مجلد dist
```

## ملاحظات
- البيانات محفوظة في `localStorage` داخل المتصفح، ويأتي التطبيق مع بيانات تجريبية (6 صفوف، 120 طالباً، 12 معلماً).
- لنقل البيانات بين الأجهزة استخدم "تصدير/استيراد نسخة احتياطية" من الإعدادات.
- تسجيل الدخول للعرض فقط وليس حماية حقيقية لأن التطبيق يعمل بالكامل في المتصفح. للاستخدام الفعلي مع عدة مستخدمين يلزم خادم وقاعدة بيانات.
- يُنشر تلقائياً على GitHub Pages عند الدفع إلى فرع `main` (عبر `.github/workflows/deploy.yml`).
